# Long-Form & Short-Form Scriptwriting

## Process
1. Confirm the format (`Short 15-60s`, `Long-Form YouTube / Tutorial`, or `Written Carousel / Article`).
2. Produce 3 Hook options for the first 3–5 seconds.
3. Write a conversational, zero-fluff script broken into clear story/teaching beats with pattern interrupts, ending with a strong takeaway or seamless replay loop.
