# Content Creation Master Suite

Primary router for video/podcast scriptwriting, visual storyboarding, edit timelines, and packaging.

## Suite Directory & Child Skills

| Skill Name | Description & When to Activate | Child Path |
| :--- | :--- | :--- |
| **`hook-and-scriptwriting`** | Write high-retention scripts for talking-head videos, YouTube tutorials, podcasts, carousels, or 15-60s Shorts. | [`hook-and-scriptwriting/SKILL.md`](hook-and-scriptwriting/SKILL.md) |
| **`storyboard-and-visual-direction`** | Map camera shots, B-roll, screen captures, graphics, or AI image/video prompts for each script beat. | [`storyboard-and-visual-direction/SKILL.md`](storyboard-and-visual-direction/SKILL.md) |
| **`audio-and-edit-timeline`** | Specify cut pacing, B-roll overlays, music shifts, SFX cues, and caption styles. | [`audio-and-edit-timeline/SKILL.md`](audio-and-edit-timeline/SKILL.md) |
| **`thumbnail-title-and-packaging`** | Create title + thumbnail pairs, chapters, captions, and a pre-publish retention check. | [`thumbnail-title-and-packaging/SKILL.md`](thumbnail-title-and-packaging/SKILL.md) |
