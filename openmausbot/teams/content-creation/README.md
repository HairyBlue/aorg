# Content Creation, Video & Production Crew (`content-creation`)

An importable 5-agent content creation and video production studio for **OpenMausBot**, led by **Showrunner (`showrunner`)**.

Supports **all content formats**—talking-head videos, YouTube long-form, screen-recorded tutorials, B-roll documentaries, Shorts/Reels/TikToks, written carousels, and optional AI short-clips.

## Contents

- [`team.md`](team.md) — **BotMRR v1 single-file import package** (`Teams -> Import`).
- [`team.mausteam.json`](team.mausteam.json) — Legacy compatibility manifest (`openmaus.team` v1); does not bundle standalone skills.
- [`skills/`](skills/) — Standalone skill files (`hook-and-scriptwriting`, `storyboard-and-visual-direction`, `audio-and-edit-timeline`, `thumbnail-title-and-packaging`).
