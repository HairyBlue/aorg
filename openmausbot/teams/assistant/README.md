- [`TEAM.md`](TEAM.md) — Full 6-agent roster (`concierge`, `job-scout`, `mpor-reporter`, `inbox-triage`, `second-brain`, `admin-ops`), 3 shared rooms, and 4 paused routines.
- [`skills/`](skills/) — Standalone skill files (`personal-day-planning`, `inbox-and-notes-triage`, `job-hunt-onlinejobs`, `mpor-progress-report`).
