# Content Creation, Video & Production Crew (`content-creation`)

A 5-agent content creation and video production studio led by Showrunner. Supports all content formats—talking-head videos, screen-recorded tutorials, YouTube long-form, TikTok/Reels/Shorts, faceless documentaries, written carousels, and optional AI short-clips—covering hooks, scripts, A-roll/B-roll storyboards (plus optional AI image/video prompts), CapCut/Premiere edit sheets, and thumbnail/title packaging.

- **Team Head:** `showrunner`
- **Bots (5):** `showrunner`, `script-writer`, `visual-director`, `edit-producer`, `growth-packager`
