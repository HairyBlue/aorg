# Software Engineering Crew (`engineering`)

A 9-agent software engineering crew led by Tech Lead. Coordinates read-only codebase scouting, architecture review, parallel backend and frontend implementation across non-overlapping files, deterministic build/typecheck/lint verification without unrequested test bloat, and independent code and security review.

- **Team Head:** `tech-lead`
- **Bots (9):** `tech-lead`, `scout`, `researcher`, `architect`, `backend`, `frontend`, `fullstack`, `qa-reviewer`, `devops-guard`
